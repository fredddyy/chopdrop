# ChopDrop Brand Design System — Canva/Figma Template Guide

This is your reference sheet. Open it every time you design anything.

---

## THE PALETTE

```
PRIMARY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Coral           #F05F4B     ← CTAs, prices, highlights, energy
Deep Green      #0F4030     ← Headers, premium cards, trust
Amber           #F5C565     ← Accents, badges, warmth
Cream           #FAFAF8     ← Backgrounds, breathing room
Ink             #1A1A1A     ← Body text, headlines

SUPPORTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Light Grey      #F5F5F3     ← Cards, subtle backgrounds
Mid Grey        #9CA3AF     ← Secondary text, captions
Soft Green      #E8F5E9     ← Success states, positive callouts
White           #FFFFFF     ← Clean cards on cream backgrounds
```

### How to use color:

- **80% of every design** is cream (#FAFAF8) or white — let it breathe
- **Coral** is your "look here" color. Use it for ONE thing per slide — the price, the CTA, the key word. Never coral on coral.
- **Deep green** is your authority color. Use it for headers on dark cards, premium sections. It says "we're serious."
- **Amber** is your warmth color. Badges, small highlights, the "₦0 delivery" pill. It makes things feel friendly.
- **Never** use red, blue, purple, or neon anything. If it's not in this palette, it doesn't exist.

## THE FONTS

```
HEADLINES / DISPLAY
━━━━━━━━━━━━━━━━━━━
Font:    Manrope
Weight:  800 (ExtraBold)
Tracking: -0.03em (tighter than default)
Use:     Slide titles, hero text, big numbers

In Canva: Search "Manrope" → select ExtraBold
If Manrope unavailable: use "Inter" ExtraBold or "DM Sans" Bold


BODY / SUPPORTING TEXT
━━━━━━━━━━━━━━━━━━━━━━
Font:    DM Sans
Weight:  400 (Regular) for body, 500 (Medium) for labels, 700 (Bold) for emphasis
Use:     Descriptions, captions, small text, labels

In Canva: Search "DM Sans"
If unavailable: use "Inter" or "Plus Jakarta Sans"


NUMBERS / PRICES
━━━━━━━━━━━━━━━━
Font:    Manrope 800
Special: Always use the ₦ symbol, never "NGN" or "Naira"
Format:  ₦1,600 not ₦1600. Always comma-separate thousands.
```

### Font size hierarchy (for 1080x1350 Instagram):

```
Hero number (₦0, ₦18,000):     120–160pt
Slide headline:                  48–64pt
Sub-headline:                    28–36pt
Body text:                       20–24pt
Caption / fine print:            14–18pt
```

## THE LAYOUT GRID

Every design sits on the same invisible structure:

```
┌──────────────────────────────────┐
│  80px padding on all sides       │
│  ┌──────────────────────────┐    │
│  │                          │    │
│  │     CONTENT ZONE         │    │
│  │                          │    │
│  │                          │    │
│  │                          │    │
│  │                          │    │
│  └──────────────────────────┘    │
│                                  │
│  [logo or swipe cue — bottom]    │
└──────────────────────────────────┘

Safe zone: 80px from every edge
Instagram crops slightly — never put text closer than 60px to any edge
```

### Alignment rules:

- **Left-align text** by default. Centered text only on brand cards (logo reveal, CTA slides).
- **One focal point per slide.** If the slide has a big number, everything else is small. If the slide has a comparison, both columns get equal weight.
- **Vertical rhythm:** Keep consistent spacing between elements. 24px between lines, 40px between sections.

## THE 5 SLIDE TEMPLATES

Save these as Canva templates. Every piece of content you ever make is one of these five.

---

### TEMPLATE 1: "THE HOOK" (Opening slide)

**When to use:** First slide of any carousel. The scroll-stopper.

```
┌──────────────────────────────┐
│                              │
│  Background: Cream #FAFAF8   │
│                              │
│                              │
│  Your office lunch           │  ← Manrope 800, 52pt, Ink
│  is STRESSING you.           │  ← "STRESSING" in Coral, 56pt
│                              │
│                              │
│                              │
│                              │
│                              │
│  [ChopDrop icon]     →       │  ← Small logo bottom-left, arrow bottom-right
└──────────────────────────────┘
```

**Rules:**
- Maximum 2 lines of text
- ONE word in coral (the emotional trigger word)
- Tons of whitespace — resist filling it
- Small logo mark (icon only, no wordmark) bottom-left
- Arrow or "swipe →" bottom-right

---

### TEMPLATE 2: "THE SPLIT" (Comparison slide)

**When to use:** Us vs them, before/after, left vs right.

```
┌──────────────┬───────────────┐
│              │               │
│  Light grey  │  Cream/White  │
│  #F0F0F0     │  #FAFAF8      │
│              │               │
│  The other   │  ChopDrop     │  ← Labels, 14pt, bold
│  way         │               │
│              │               │
│  ₦800        │  ₦0           │  ← Big numbers
│  delivery    │  delivery.    │
│              │               │
│  [sad stat]  │  [happy stat] │
│              │               │
│              │    ✓          │  ← Green check on our side
└──────────────┴───────────────┘
```

**Rules:**
- Left side: muted, grey text, smaller font — make it feel heavy/tired
- Right side: bold, dark text, bigger font — make it feel clean/light
- Never more than 3 comparison points per slide
- The visual weight should LEAN right (towards ChopDrop)

---

### TEMPLATE 3: "THE STAT" (Big number slide)

**When to use:** Key numbers, prices, savings, milestones.

```
┌──────────────────────────────┐
│                              │
│  Background: Coral #F05F4B   │
│  (or Deep Green #0F4030)     │
│                              │
│                              │
│         ₦0                   │  ← Manrope 800, 140pt, White
│         delivery.            │  ← 36pt, White
│                              │
│                              │
│  When 20 people order to     │  ← 18pt, White/70%
│  one address, delivery       │
│  should be free. So it is.   │
│                              │
└──────────────────────────────┘
```

**Rules:**
- Full-bleed background (coral OR green, never both)
- One number, massive. Center of slide. White text.
- Supporting text is small and low opacity (70%)
- This template is ONLY for numbers: ₦0, ₦18,000, 25 meals, 90 seconds

**Color rules for stat slides:**
- Coral background → for shocking/attention numbers (₦0, ₦18,000/month)
- Green background → for trust/achievement numbers (100 meals delivered, 10 offices)

### TEMPLATE 4: "THE STORY" (Text-heavy slide)

**When to use:** Explanations, how-it-works, the "honest" slide, testimonials.

```
┌──────────────────────────────┐
│                              │
│  Background: Cream or White  │
│                              │
│  [Eyebrow — 12pt, grey,     │  ← "HOW IT WORKS" or "THE HONEST TRUTH"
│   uppercase, tracked out]    │
│                              │
│  Those apps are great.       │  ← Manrope 800, 36pt
│                              │
│  For Saturday night suya.    │  ← DM Sans 400, 22pt, grey
│  For Sunday sharwarma.       │
│                              │
│  But Monday to Friday?       │  ← DM Sans 700, 22pt, ink
│  You need something built    │
│  for exactly that.           │  ← "exactly that" in coral
│                              │
└──────────────────────────────┘
```

**Rules:**
- Left-aligned, always
- Maximum one color accent (one phrase in coral or amber)
- Generous line height (1.6x)
- Eyebrow label at top in small grey uppercase — grounds the slide
- This is your most "editorial" template — it should feel like a magazine page, not a poster

### TEMPLATE 5: "THE CTA" (Closing slide)

**When to use:** Last slide of any carousel. Drive action.

```
┌──────────────────────────────┐
│                              │
│  Background: Ink #1A1A1A     │
│  (or Cream for lighter feel) │
│                              │
│      [ChopDrop logo]         │  ← Full logo (icon + wordmark), white
│                              │
│  Meals for offices, sorted.  │  ← 24pt, white/80%
│                              │
│  ┌────────────────────────┐  │
│  │ Start ordering today → │  │  ← Amber fill, dark text, rounded
│  └────────────────────────┘  │
│                              │
│  chopdrop-app.vercel.app     │  ← 16pt, white/50%
│                              │
│  Now serving Ikeja.          │  ← 14pt, white/40%
│  @chopdrop.ng                │
│                              │
└──────────────────────────────┘
```

**Rules:**
- Logo is centered and bigger than anywhere else (this is the ONE place it dominates)
- CTA button is amber with dark text — highest contrast element on the slide
- URL is understated, not screaming
- Dark background (ink or green) for premium feel, cream background for friendly feel
- This slide should feel like a landing — confident, still, resolved

## THE LOGO USAGE

```
FULL LOGO (icon + wordmark):
- Only on CTA slides, brand cards, and headers
- Minimum size: 120px wide
- Always on solid backgrounds (never on busy images)

ICON ONLY (coral teardrop):
- On hook slides, corners, watermarks
- Minimum size: 32px
- Can sit on images with enough contrast

NEVER:
- Stretch the logo
- Put it on a clashing background
- Make it the biggest thing on a content slide (the MESSAGE is biggest)
- Use it more than once per slide
```

## THE PHOTO STYLE

When you use photos (food, office, people):

```
DO:
- Warm, natural lighting (daylight or warm indoor)
- Real Nigerian food (not stock photos of sushi)
- Real office environments (not WeWork San Francisco)
- Slightly overhead angle for food (45° works)
- Show steam, color, texture — make them hungry

DON'T:
- Use cold/blue lighting
- Use American/European stock food photos
- Over-filter or over-saturate
- Use photos with visible competing brand logos
```

**Photo treatment:**
- Round the corners (16–24px radius) when placing in slides
- Add a subtle shadow (0px 4px 16px, black at 8% opacity)
- If the photo is busy, add a dark overlay (black at 30–40%) before putting text on it

## QUICK REFERENCE: THE CHOPDROP LOOK

If someone sees your design and can instantly tell it's ChopDrop without reading a word, you've done it right. The brand should feel:

```
✓ Clean but warm (not sterile, not chaotic)
✓ Confident but friendly (not corporate, not childish)
✓ Nigerian but modern (not traditional, not foreign)
✓ Premium but accessible (not luxury, not budget)
```

**The vibe check:**
- Does it look like it could be a Chowdeck competitor? → Good
- Does it look like a bank ad? → Too corporate, add warmth
- Does it look like a meme page? → Too casual, add structure
- Does it feel like Apple designed a Lagos food app? → Perfect

## CANVA SETUP CHECKLIST

Do this once. Takes 15 minutes. Saves hours.

```
1. Create a Brand Kit in Canva:
   - Add all 5 brand colors
   - Upload Manrope and DM Sans fonts (or select from Canva)
   - Upload ChopDrop logo (icon + wordmark versions)

2. Create 5 blank templates (1080x1350):
   - "Hook" template
   - "Split" template  
   - "Stat" template
   - "Story" template
   - "CTA" template

3. Save each with the correct:
   - Background color
   - Text placeholders with correct fonts/sizes
   - Logo placement
   - 80px padding guides

4. Every new carousel: duplicate a template, swap the text.
   That's it. 10 minutes per slide, not 45.
```

## THE GOLDEN RULE

> Every design you make should pass this test:
> If someone screenshots one slide and sends it to their 
> office WhatsApp group with no caption — does it make sense?
> Does it make them want to know more?
> 
> If yes → post it.
> If no → simplify until it does.
